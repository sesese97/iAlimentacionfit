# MealFit MX

Prototipo inicial de planificador de comidas mexicano con enfoque fitness y preparación de despensa.

## Estado
- Recetas de demostración y valores nutricionales ilustrativos, **no validados**.
- Lista consolidada de ingredientes, selección de supermercado y menú semanal.
- **Sin integración activa con supermercados, sin precios actuales ni carritos automáticos.**

## Desarrollo
`npm install && npm run dev`
