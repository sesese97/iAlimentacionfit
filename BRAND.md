# MealFit MX · Performance Fuel
Identidad visual v1.0

## Posicionamiento
Nutrición para entrenar, rendir y vivir mejor. No se presenta como una app vegetariana ni como una marca de suplementos. Combina energía deportiva con la facilidad de consultar recetas y hacer compras.

## Paleta
- Navy / tinta principal: `#101B2D`. Titulares, navegación activa, métricas, logotipo y superficies de contraste.
- Orange / energía: `#FF6B3D`. CTA principal, progreso, selección activa y proteína.
- Blue / carbohidratos: `#4D86D8`.
- Gold / grasas: `#E8B55C`.
- Slate / panel secundario: `#1D2B42`.
- Canvas / fondo: `#F5F7FB`.
- Muted / texto auxiliar: `#71829C`.
- Border / divisores: `#E3E8F0`.
- White / tarjetas: `#FFFFFF`.

## Reglas de uso
1. La experiencia de lectura y las fotografías de comida viven en fondos claros.
2. Navy identifica estructura, navegación y paneles de rendimiento.
3. Orange se reserva para CTA, acciones, foco y selección. No usar como color para párrafos extensos.
4. Macros: proteína naranja, carbohidratos azul, grasas dorado. Calorías en navy.
5. Usar Manrope para titulares y DM Sans para interfaz y cuerpo.
6. Botones con esquinas redondeadas, tarjetas limpias y fotografía protagonista.
7. Mensajes de precaución usan fondo durazno y texto oscuro, nunca naranja intenso sobre blanco en texto pequeño.
8. Las cifras de recetas y las comparaciones de supermercados solo se presentan como verificadas cuando existan fuentes y cálculos trazables.

## Producto
Mantener todos los flujos: onboarding, edición de macros, selección múltiple de supermercados, plan, recetas, compras y advertencias de datos pendientes. El cambio de marca no altera cálculos ni integraciones.
